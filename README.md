# 🚴 Citi Bike Data Visualization

## 📌 Project Overview

This project presents an interactive web-based visualization of Citi Bike ride data, utilizing JavaScript and D3.js to provide insights into bike-sharing patterns in New York City.

## 🧰 Technologies Used

- **JavaScript**: Core scripting language for interactivity.
- **D3.js**: Library for data-driven document manipulation and visualization.
- **HTML/CSS**: Structure and styling of the web pages.

## 📁 Repository Structure

- `index.html`: Main HTML file that serves as the entry point for the web application.
- `static/`: Directory containing static assets such as JavaScript, CSS, and data files.
- `.github/workflows/`: Contains GitHub Actions workflows for automation tasks.
- `README.md`: Provides an overview and instructions for the project.
